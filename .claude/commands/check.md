このコマンドは **読み取り専用** です。ファイルは変更しません。

以下を順に実行し、最後に日本語で要約してください。

1. **秘密情報のチェック**：
   - `rg -n 'sk_(live|test)_[A-Za-z0-9]{16,}' --glob '!.env*' --glob '!*.md'` を実行
   - `rg -n 'AKIA[0-9A-Z]{16}' --glob '!.env*'` を実行
   - `rg -n 'eyJ[A-Za-z0-9_-]{20,}\\.[A-Za-z0-9_-]{20,}\\.[A-Za-z0-9_-]{20,}' --glob '!*.md'` を実行
   - 何かヒットしたらそれは **NG**

2. **型チェック**（`tsconfig.json` が存在する場合のみ）：
   - `npx tsc --noEmit` を実行
   - エラーがあれば件数を控える

3. **未保存の変更**：
   - `git status --short` で未コミットのファイル一覧を取得

4. **ブランチ確認**：
   - `git branch --show-current` で現在のブランチを取得
   - `develop` 以外なら警告

5. **日本語で結果を表示**（次のフォーマット）：

```
✅ または ⚠️ チェック結果

🔐 秘密情報：問題なし / 〇件ヒット
📐 型エラー：問題なし / 〇件
📝 未保存の変更：なし / 〇ファイル
🌿 ブランチ：develop ✅ / 〇〇 ⚠️

→ 次にやること：…
```

## 大切なこと

- ファイルは絶対に変更しないこと
- ヒットした内容は具体的に表示（ファイル名と行番号）
- 問題があれば、修正方法を日本語で簡単に伝える
