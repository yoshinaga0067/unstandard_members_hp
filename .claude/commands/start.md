このコマンドが呼ばれたら、以下を **この順序で** 実行してください。途中で問題があれば日本語でユーザーに伝えてください。

## ステップ0：リポジトリの確認（最初に必ず行う）

`git remote get-url origin` でリモートURLを取得する。

**以下のいずれかに該当する場合は、作業を中断してユーザーに日本語で伝える：**

- リモートが設定されていない（`git remote` が空）
- リモートURLに `claude-md-template` が含まれている（テンプレートのリポジトリそのまま）

その場合のメッセージ（フレンドリーに）：
```
⚠️ このフォルダはテンプレートのままです。作業を始める前に、ご自身のGitHubリポジトリを作成して紐付ける必要があります。

以下の手順で進めてください：

1. GitHub（github.com）にログインする
2. 右上の「+」→「New repository」をクリック
3. リポジトリ名を入力して「Create repository」をクリック
4. 作成後に表示されるリポジトリのURL（例：https://github.com/あなたのアカウント名/リポジトリ名）を教えてください

URLを教えていただければ、あとはこちらで紐付けて始められます！
```

リモートURLが別のリポジトリを指していれば問題なし。次のステップへ進む。

## ステップ1以降：通常の起動フロー

1. 現在のブランチを確認（`git branch --show-current`）
2. `develop` ブランチが存在しない場合は `git checkout -b develop` で作成。存在する場合は `git checkout develop`
3. `git pull origin develop` で最新版を取得
4. `CLAUDE.md` を読んでプロジェクトのルールを確認
5. `PROJECT-OVERVIEW.md` が存在すれば読んで、プロジェクトの概要を把握
6. プロジェクト直下のファイル構造を簡単に把握（`ls` 程度でOK）
7. **日本語で** 以下をユーザーに伝える：
   - 今 develop ブランチにいること
   - プロジェクトが何のためのものか（PROJECT-OVERVIEW.md から）
   - すでに作られている主な機能・ページ
   - 今日これから何をしたいか質問する

## 大切なこと

- 技術的な用語はなるべく避けてください（「ブランチ」程度はOK）
- 「準備できました。今日は何を作りますか？」のように、フレンドリーに締めくくってください
- ファイルを編集する必要はまだありません。状況把握だけです
