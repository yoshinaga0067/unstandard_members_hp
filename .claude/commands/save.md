description: ここまでの変更をdevelopブランチにコミットして保存します。コミットメッセージは日本語で自動生成します。
---

このコマンドが呼ばれたら、以下を実行してください。

1. 現在のブランチを `git branch --show-current` で確認
   - **`main` または `master` だった場合は即停止**して、ユーザーに「mainブランチでは保存できません。`/start` で develop に切り替えてください」と日本語で伝える
2. `git status` と `git diff --stat` で変更内容を確認
3. 変更が無ければ「保存する変更がありません」と伝えて終了
4. 変更があれば、変更内容から **短く明確な日本語のコミットメッセージ** を生成
   - 例：「ヘッダーのデザインを変更」「物件一覧ページを追加」「お問い合わせフォームのバリデーションを修正」
   - 動詞は「追加 / 変更 / 修正 / 削除」のいずれか
5. `git add -A` でステージング（`.env*` は .gitignore で守られているので安全）
6. `git commit -m "<生成したメッセージ>"` でコミット
7. **日本語で** 結果を伝える：「『〇〇』として保存しました。続けて作業できます。」

## 大切なこと

- ユーザーに技術的な詳細（コミットハッシュ等）は見せない
- プッシュ（GitHubにアップロード）はしない。プッシュは `/publish` の役割
- コミットメッセージに英語を混ぜない
