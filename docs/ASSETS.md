# 画像・アセット取り扱いガイド

物件写真や画像素材の保存先・サイズ・著作権ルールです。住宅会社のアプリは画像が中心になるので、ばらつきが出ないようにします。

## 保存先

### フェーズ1（デモ作成中）

**Supabase Storage を使わない場合**
- 保存先：`/public/properties/<id>/<filename>.jpg`
- 例：`/public/properties/p001/hero.jpg`
- このパスはブラウザに公開されます（秘密情報は入れないこと）

**Supabase Storage を使う場合**
- バケット名：`property-photos`
- RLS：デモ中は public-read で OK
- アップロード時のキー命名：`<property_id>/<role>.jpg`（例：`p001/hero.jpg`）

### フェーズ3（エンジニアレビュー後）

- エンジニアが事前にバケットや CDN を用意している前提
- 保存先や RLS の設定を変更しないこと
- 変更が必要な場合はエンジニアに相談する

## サイズと最適化

### Next.js プロジェクト
- **必ず `next/image` を使う**（`<img>` タグの直書きは避ける）
- 自動で WebP 変換 + lazy load されます

### 推奨サイズ
| 用途 | 寸法 | 形式 |
|------|------|------|
| ヒーロー画像 | 1920 x 1080 | JPG（写真）／ WebP |
| 物件サムネイル | 640 x 480 | JPG |
| 物件詳細ギャラリー | 1280 x 960 | JPG |
| アイコン・ロゴ | 任意 | SVG（拡大しても劣化しない） |
| OGP（SNS シェア用） | 1200 x 630 | JPG／PNG |

### alt テキスト
- **必ず日本語で記述**
- 例：「リビングから見た南向きの窓」「キッチンの全景」
- 装飾画像は `alt=""`（空文字）で OK — スクリーンリーダーがスキップします

## 著作権・透かし

### デモ用の画像
- フリー素材：Unsplash、Pexels、写真AC など
- 自社撮影の物件写真
- **クライアント物件の写真は許可なしに使わないこと**

### 本番公開時の透かし
- HARMONY ブランド：右下に小さく `© HARMONY` を入れる
- UNSTANDARD ブランド：右下に小さく `© UNSTANDARD` を入れる
- カスタム：プロジェクトごとに判断
- 環境変数 `NEXT_PUBLIC_SHOW_WATERMARK=true` で本番だけ表示する実装が推奨

### 画像差し替え時の注意
- 物件の引き渡し後、お客様から「写真を取り下げてほしい」と要望が出ることがあります
- アップロード元（撮影者・許諾日）を別途記録しておくとトラブルを防げます

---

## アクセシビリティとパフォーマンス

- `next/image` の `priority` 属性は **ファーストビューの 1〜2枚のみ** に使う（多用すると LCP が悪化）
- 装飾画像（背景パターン等）は CSS で実装するか、`loading="lazy"`
- 文字の代わりに画像を使わない（読み上げ・検索の妨げになる）

---

## やってはいけないこと

- お客様の顔がはっきり写った写真を許可なしに公開しない（個人情報・肖像権）
- 高解像度のオリジナル画像をそのままアップロードしない（リサイズしてからアップ）
- ストックフォトを「自社物件」として掲載しない（景品表示法・優良誤認）
- 透かし入りのフリー素材をそのまま使わない
