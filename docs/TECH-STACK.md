# 技術スタック（Tech Stack）

このプロジェクトで使用する技術の一覧です。
基本は **Next.js**。シンプルな社内ツールに限り Vite を使うことがあります。
判断は Claude Code に任せてください。

## フレームワーク

| 選択肢 | 使う場面 |
|--------|---------|
| **Next.js (App Router)** | デフォルト。お客様向けアプリ、認証あり、API接続、SEOが必要な場合 |
| React + Vite | シンプルな社内ツールのみ。Claude Code が判断します |

## 共通ライブラリ

| ライブラリ | 用途 |
|-----------|------|
| Tailwind CSS | スタイリング（デザイン） |
| TypeScript | 型安全（コードの品質向上） |
| Noto Sans JP | 日本語フォント |
| zod | 入力値のバリデーション（検証） |

## 認証が必要な場合

| ライブラリ | 用途 |
|-----------|------|
| NextAuth.js / Auth.js | ログイン・認証機能 |
| Supabase Auth | バックエンドが Supabase の場合 |

## デプロイ先

| サービス | 用途 |
|---------|------|
| Vercel | ウェブサイトの公開（自動） |
| GitHub | ソースコードの管理 |

## 環境変数

秘密情報（APIキー、パスワード等）は全て環境変数で管理します。
`.env.example` にどんな環境変数が必要か記載されています。
実際の値はエンジニアがVercelに設定します。

## MCP・拡張機能・サードパーティツール

- **追加しないでください。** MCPサーバー、ブラウザ拡張、Claude Code のサードパーティプラグインは、サプライチェーン攻撃の入り口になります
- どうしても必要な場合は、エンジニアに相談してください
- 既にプロジェクトに含まれているもの以外は使わない、が基本ルールです

## 注意

- 技術の選択は Claude Code に任せてください
- セキュリティ関連のライブラリ（zod, NextAuth等）は必ず使用します
- 不要なライブラリは追加しません
- 分からない技術名が出てきたら、用語集を確認してください
