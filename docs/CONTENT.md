# 日本語コピーガイド

このプロジェクトで使う日本語の書き方のルールです。住宅会社の Web サイトとして読みやすく、業界の慣習に沿った表記を目指します。

## 敬語レベル

テーマに応じて使い分けます：

| テーマ | レベル | 例 |
|--------|--------|-----|
| **HARMONY** | 穏やかな敬語、です／ます調 | 「ご相談を承っております」「お客様の暮らしに寄り添う家づくりをご提案いたします」 |
| **UNSTANDARD** | 軽い敬語＋会話調 | 「あなたの『好き』から、家づくりを始めよう」「気になることは、お気軽にどうぞ」 |
| **カスタム** | プロジェクトに合わせる | — |

共通ルール：
- 過度な謙譲語は避ける（「拝見させていただきます」より「拝見します」）
- ら抜き言葉は避ける（「見れる」→「見られる」）
- 句点（。）を文末に必ずつける

## 住宅業界の表記ルール

### 面積
- **メイン：平米（㎡）**
- 補助：坪（必要なら括弧書きで併記）
- 例：「90.5㎡（27.4坪）」

### 間取り
- 標準表記：1LDK / 2LDK / 3LDK / 4LDK
- 階数表記：2階建 / 3階建
- 例：「3LDK・2階建・92.0㎡」

### 価格
- **単位：万円**（円表記は避ける）
- 税込／税別を必ず明記
- 例：「2,980万円（税込）」「3,200万円〜（税別）」
- 月々支払いの目安を併記する場合：「月々8.2万円〜（35年ローン・金利1.5%）」

### 立地
- 駅徒歩は分単位、80m/分で計算（不動産公正取引協議会の規定）
- 例：「JR名古屋駅 徒歩12分」

## フォーム関連

### 必須表示
- 必須項目は赤字で「必須」と表示
- 任意項目は「任意」（グレー）を併記すると親切

### よく使うフィールド（お問い合わせフォーム例）
- お名前（必須）
- フリガナ（必須）
- メールアドレス（必須）
- 電話番号（必須）
- 希望エリア（任意）
- 希望予算（任意）
- お問い合わせ内容（必須）

### エラーメッセージ例
| 場面 | メッセージ |
|------|-----------|
| 未入力 | お名前を入力してください |
| メール形式 | 正しいメールアドレスを入力してください |
| 電話形式 | 正しい電話番号を入力してください（半角数字） |
| 文字数オーバー | 200文字以内で入力してください |
| 送信成功 | お問い合わせを受け付けました。担当者よりご連絡いたします。 |
| 送信失敗 | 送信に失敗しました。お手数ですが、しばらく経ってからもう一度お試しください。 |

### Placeholder 例
- お名前 → `山田 太郎`
- フリガナ → `ヤマダ タロウ`
- メール → `taro@example.com`
- 電話 → `09012345678`

英語の placeholder（`Your name`、`Enter email` 等）は使わないこと。

## ボタン・CTA の言葉づかい

| 用途 | HARMONY 風 | UNSTANDARD 風 |
|------|-----------|--------------|
| 問い合わせ | お問い合わせはこちら | 話を聞いてみる |
| 資料請求 | 資料を請求する | カタログをもらう |
| 来店予約 | 来店予約 | お店に行ってみる |
| 詳細を見る | 詳細を見る | もっと見る |
| 送信 | 送信する | 送る |

---

## 避ける表現

- カタカナ語の濫用（「コンセプト」「ライフスタイル」は OK、無理にカタカナ化しない）
- 専門用語（「気密性能 C 値」のような数値は注釈付きで）
- 不確実な断定（「絶対」「必ず」「100%」）
- 誇大表現（景品表示法に注意）
