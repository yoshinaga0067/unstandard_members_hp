# ワークフロー早見表

## プロジェクトには3つのフェーズがあります

```
フェーズ1：デモ作成（スタッフ主導）
　　↓
フェーズ2：エンジニア引き継ぎ（エンジニア主導）
　　↓
フェーズ3：機能追加（スタッフ主導・エンジニアの基盤の上で）
```

---

## フェーズ1：デモを作る（エンジニア不要）

「こんなアプリが欲しい」というイメージを形にするフェーズです。
データベースや本番環境は不要。アイデアを見せるデモを作ります。

### 手順

1. **このテンプレートをダウンロードする**
   - GitHubからクローンまたはダウンロード
   - Claude Code でフォルダを開く

2. **開発を始める**
   - **`/start`** と入力（または「始めて」）
   - 作りたいものを日本語で自由に伝える：
     - 「物件一覧と詳細ページを作りたい」
     - 「問い合わせフォームが欲しい」
     - 参考サイトがあれば一緒に伝えると◎

3. **こまめに保存する**
   - 区切りごとに **`/save`**（または「保存して」）

4. **デモを共有する**
   - **`/publish`** と入力（または「公開して」）
   - プレビューURLが生成されます
   - 上長・チーム・クライアントに見せて確認してもらう

5. **デモが固まったら → エンジニアに連絡する**
   - 「デモができました」とエンジニアに伝える
   - エンジニアがここから引き継ぎます

---

## フェーズ2：エンジニアが本番環境を準備する（待つ）

スタッフは待つだけです。エンジニアがやること：

- デモを確認・整理
- データベース（テーブル設計）を構築
- 認証（ログイン）機能をセットアップ
- API接続・バックエンドロジックを実装
- 開発環境・本番環境（Vercel等）を準備
- 新しいリポジトリを作成して、スタッフが使えるよう整える

準備完了の連絡が届いたら、フェーズ3へ進みます。

---

## フェーズ3：機能を追加する（エンジニアの基盤の上で）

エンジニアが準備したリポジトリを使って、画面や機能を追加するフェーズです。

### 手順

1. **エンジニアのリポジトリをクローンする**
   - Claude Code でそのフォルダを開く

2. **開発を始める**
   - **`/start`** と入力
   - 現在の状態が確認され、何が作られているか教えてくれます

3. **機能を追加する**
   - 「〇〇ページにフィルター機能を追加したい」など、日本語で指示
   - エンジニアが設定したデータベース・認証・API設定は変更しない

4. **保存・確認・公開**
   - `/save` → `/check` → `/publish` の流れで作業

### フェーズ3での注意点

- ⚠️ データベースの構成・ログイン・API設定は変更しないでください（フックが自動で防ぎます）
- ⚠️ APIキーやパスワードをコードに書かないでください
- ✅ 画面のデザインや新しいページは自由に作れます

---

## 困ったら

- Claude Code に「エラーが出た。直して」と指示する
- フックが「🚫」で止まったら → メッセージの「✅ 正しい手順」に従う
- 「エンジニアに相談してください」と言われたら → エンジニアに連絡する
