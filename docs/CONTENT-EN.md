# Japanese Copy Guide

How to write Japanese copy for this project. Aim: readable for housing-company websites, aligned with industry conventions.

## Politeness level (keigo)

Match it to the theme:

| Theme | Level | Example |
|-------|-------|---------|
| **HARMONY** | Calm formal — です／ます | 「ご相談を承っております」「お客様の暮らしに寄り添う家づくりをご提案いたします」 |
| **UNSTANDARD** | Light keigo + conversational | 「あなたの『好き』から、家づくりを始めよう」「気になることは、お気軽にどうぞ」 |
| **Custom** | Match the project | — |

Universal rules:
- Avoid over-humble forms (「拝見させていただきます」 → just 「拝見します」)
- Avoid ra-nuki (「見れる」 → 「見られる」)
- Always end sentences with 。

## Housing-industry conventions

### Area
- **Primary: square meters (㎡)**
- Secondary: tsubo (坪) in parentheses if helpful
- Example: 「90.5㎡（27.4坪）」

### Floor plan
- Standard: 1LDK / 2LDK / 3LDK / 4LDK
- Floor count: 2階建 / 3階建
- Example: 「3LDK・2階建・92.0㎡」

### Price
- **Unit: 万円 (10,000 yen)** — never raw yen
- Always state tax-inclusive (税込) or tax-exclusive (税別)
- Example: 「2,980万円（税込）」「3,200万円〜（税別）」
- Monthly payment example: 「月々8.2万円〜（35年ローン・金利1.5%）」

### Location
- Walking time: minutes, calculated at 80m/minute (legal standard)
- Example: 「JR名古屋駅 徒歩12分」

## Forms

### Required field display
- Mark required fields with red 「必須」
- Optionally mark optional fields with gray 「任意」

### Common inquiry form fields
- Name (required)
- Furigana (required)
- Email (required)
- Phone (required)
- Preferred area (optional)
- Budget range (optional)
- Inquiry content (required)

### Error message templates
| Case | Message |
|------|---------|
| Missing input | お名前を入力してください |
| Email format | 正しいメールアドレスを入力してください |
| Phone format | 正しい電話番号を入力してください（半角数字） |
| Length limit | 200文字以内で入力してください |
| Submit success | お問い合わせを受け付けました。担当者よりご連絡いたします。 |
| Submit failure | 送信に失敗しました。お手数ですが、しばらく経ってからもう一度お試しください。 |

### Placeholder examples
- Name → `山田 太郎`
- Furigana → `ヤマダ タロウ`
- Email → `taro@example.com`
- Phone → `09012345678`

Do **not** use English placeholders like `Your name` or `Enter email`.

## Button / CTA wording

| Purpose | HARMONY style | UNSTANDARD style |
|---------|---------------|-------------------|
| Contact | お問い合わせはこちら | 話を聞いてみる |
| Request materials | 資料を請求する | カタログをもらう |
| Book visit | 来店予約 | お店に行ってみる |
| View details | 詳細を見る | もっと見る |
| Submit | 送信する | 送る |

## Avoid

- Over-use of katakana loanwords (「コンセプト」「ライフスタイル」OK, but don't force English-isms)
- Bare technical terms (e.g. 「気密性能 C 値」 — annotate with a brief explanation)
- Absolute claims (「絶対」「必ず」「100%」)
- Exaggerated promises — Japan's advertising law (景品表示法) is strict
