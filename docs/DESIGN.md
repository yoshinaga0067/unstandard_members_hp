# デザインガイド

このプロジェクトで使うデザインの方針です。Claude Code が画面を作るときに参照します。

## テーマを選ぶ

プロジェクト開始時（`/start`）に以下のいずれかを選びます。一度選んだら `PROJECT-OVERVIEW.md` に記録され、以降のセッションでは自動で適用されます。

| テーマ | 雰囲気 | 用途 |
|--------|--------|------|
| **HARMONY** | フォーマル・温かみ・自然素材 | 親会社ブランド／お客様向けサイト |
| **UNSTANDARD** | カジュアル・カラフル・ライフスタイル中心 | 若年層向けブランド |
| **カスタム** | プロジェクト独自 | 社内ツール／実験的なデモ |

## HARMONY テーマ

### カラー（実サイト `shizensozainoie.co.jp` から抽出）

| 用途 | Hex | 説明 |
|------|-----|------|
| 背景 | `#ffffff` | 純白 |
| テキスト（本文） | `#333333` | 濃いグレー（純黒は避ける） |
| テキスト（補助） | `#555555` | やや薄いグレー |
| ブランドアクセント | `#da2308` | 赤系オレンジ — ボタン・リンク・強調 |
| サブアクセント | `#e28174` | ピーチ／コーラル — 装飾用 |
| ボーダー（強） | `#b3b3b3` | 中間グレー |
| ボーダー（弱） | `#dcdcdc` | ライトグレー |

「温かみ」は写真（暖色・低彩度）から来ています。UI 自体は白＋赤アクセント＋グレーの構成です。

Tailwind トークン例：
```ts
colors: {
  harmonyAccent: '#da2308',
  harmonyAccentLight: '#e28174',
  harmonyText: '#333333',
  harmonyTextMuted: '#555555',
  harmonyBorder: '#b3b3b3',
  harmonyBorderLight: '#dcdcdc',
}
```

### タイポグラフィ
- 日本語本文：Noto Sans JP
- 英語見出し：上品なセリフ（例：Cormorant Garamond）またはジオメトリックサンス
- 本文 line-height: 1.8
- 見出しは細め～標準ウェイト、装飾的すぎないこと

### 写真
- 自然光、暖色寄り、低彩度
- ドキュメンタリー調 — 完璧に整えた写真より、暮らしの一瞬を切り取った写真
- 素材感（木・布・植物）を活かす
- ライフスタイル中心（人物が写っていてもOK）

### トーン
- 穏やかな敬語（です／ます）
- 感情語を多めに使う：「驚きと感動」「居心地」「上質な暮らし」「こだまする」「自然素材」
- 押し付けず、ゆっくり語りかける

### レイアウト
- フルブリードヒーロー画像
- 非対称グリッド
- 余白広め
- masonry スタイルのギャラリー

### タイポグラフィ
- 日本語：クリーンなモダンサンス（Noto Sans JP）
- 英語：太字のシンプルなサンス
- 「LIFE IS COLORFUL」のような graphic な見出し表現 OK

### 写真
- 彩度高め、暖色寄り
- ライフスタイル中心 — テキスタイル、植物、本、雑貨
- 完璧に整えるより「その人らしい」ディテールを残す
- フルブリードのヒーロー画像が中心

### トーン
- 会話調、軽い敬語
- 親しみフレーズ OK：「〜してみて」「〜しよう」
- キーワード：「あなたの好き」「暮らし」「決めすぎないデザイン」

### レイアウト
- レイヤード（写真の上にテキスト重ね）
- 横スクロールカルーセル
- カード型グリッド
- Instagram／Pinterest 的な見せ方

## カスタムテーマ

プロジェクト独自のデザインを使う場合。`/start` 時に Claude が以下を質問します：

1. 参考になるウェブサイトのリンクはありますか？
2. デザインガイド（`design.md` など）はお持ちですか？

どちらか提供があれば、Claude がそこからブランド要素を読み取って、このファイルに **「プロジェクト固有デザイン」** セクションを追記します。

どちらも無ければ、以下の TODO を追記して、追って決めていきます：

```
## TODO（カスタムテーマ）
- [ ] 主要カラーを決める
- [ ] フォントを決める
- [ ] 参考サイトを追加する
```

## 共通ルール（全テーマ共通）

### レスポンシブ
- モバイル：375px
- タブレット：768px
- デスクトップ：1024px 以上
- モバイルファーストで実装

### 日本語タイポグラフィ
- 本文 line-height: 1.8
- 行間に余裕を持たせる
- 字間は調整しない（CSS の letter-spacing はデフォルト）

### アクセシビリティ
- 住宅会社のお客様は高齢の方も多い前提
- 本文サイズ 16px 以上
- コントラスト比 WCAG AA 以上
- フォーカスインジケーターを明示
- ボタンの最小タップ領域 44x44px

### フォーム
- placeholder は日本語
- 必須項目は「必須」を赤字で明示
- エラーメッセージは日本語でわかりやすく（詳細は `docs/CONTENT.md`）

### 画像
- 写真・画像の取り扱いは `docs/ASSETS.md` を参照
- `next/image` を使う
- alt テキストは必ず日本語で
