# 用語クイックリファレンス

プロジェクトでよく出てくる用語の簡単な説明です。
詳しくは、ガバナンスドキュメントサイトの用語集ページを確認してください。

| 用語 | 意味 | たとえるなら |
|------|------|-------------|
| リポジトリ | プロジェクトの全ファイルが入ったフォルダ | 物件ごとの図面フォルダ |
| ブランチ | 安全に作業するためのコピー | 間取り変更を試すための図面コピー |
| develop | 作業用のブランチ。全ての変更はここで行う | 作業中の図面コピー |
| main | 本番用のブランチ。公開されるコード | お客様に提出する正式な設計図 |
| コミット | 変更を保存すること | 設計変更にメモ付きスタンプを押すこと |
| プッシュ | 変更をGitHubにアップロード | 修正した図面を図面庫にアップロード |
| プルリクエスト (PR) | 変更の確認依頼 | 設計変更を責任者に確認依頼すること |
| マージ | 変更をmainに反映 | 承認された変更を正式図面に反映 |
| デプロイ | ウェブサイトを公開 | 完成した家をお客様に引き渡すこと |
| ビルド | コードをウェブサイトに変換 | 設計図から家を建てること |
| 環境変数 | 秘密情報の安全な保管場所 | 物件の鍵管理ボックス |
