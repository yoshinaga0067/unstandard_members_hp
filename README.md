## 開発の始め方

1. エンジニアから「準備完了」の連絡を受ける
2. Claude Code でこのリポジトリを開く
3. Claude Code に **`/start`** と入力（または「始めて」と日本語で指示）
4. 作りたいものを日本語で指示する
5. 区切りごとに **`/save`**（または「保存して」）でこまめに保存
6. 完了したら **`/publish`**（または「公開して」）と指示する
7. エンジニアのレビューを待ってから公開されます

## 使えるコマンド

| コマンド | 何をするか |
|---------|-----------|
| `/start` | 開発を開始。developブランチに切り替えて、最新版を取得 |
| `/save` | ここまでの変更を保存（コミット） |
| `/check` | 安全性チェック（秘密情報・型エラー・未保存の変更） |
| `/publish` | プルリクエストを作成して公開リクエスト |
